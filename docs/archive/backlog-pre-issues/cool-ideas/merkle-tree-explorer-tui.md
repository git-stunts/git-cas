# COOL IDEA™: Merkle Tree Explorer (TUI)

## Context
`git-cas` supports Merkle-style manifests for large assets, but these are currently opaque in the TUI dashboard.

## Description
Implement a "Drill Down" view in the `git-cas vault dashboard` that allows users to navigate the chunk hierarchy of a Merkle manifest.

## Value
- Improves transparency for large assets.
- Helps identify specific corruption points in a manifest hierarchy.
- Visual validation of the Merkle threshold logic.
