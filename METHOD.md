# METHOD

The canonical METHOD now lives in
[docs/method/process.md](./docs/method/process.md).

Short version:

- GitHub Issues and Milestones are the source of truth for actionable work.
- Repo Markdown is for design, evidence, public docs, release history, and
  historical context.
- If work is only in Markdown, it is not tracked work.
- Design cycles live under [docs/design/](./docs/design/README.md).
- Release history lives in [CHANGELOG.md](./CHANGELOG.md).

Use [WORKFLOW.md](./WORKFLOW.md) as the root signpost.
